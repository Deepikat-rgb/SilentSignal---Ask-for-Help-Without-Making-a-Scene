# 🚨 SilentSignal – Ask for Help Without Making a Scene

A Personal Safety Web app concept featuring a discreet help signal, safety check-in timer, and trusted contact setup, built with HTML, CSS, and JavaScript.

### 🛡️ A Discreet Personal Safety Web Application

## 📌 About the Project

I developed **SilentSignal** as a personal safety web application concept designed to help people discreetly seek support when they feel unsafe or uncomfortable.

The idea behind this project is to make asking for help easier in situations where speaking openly or making a phone call may be difficult. I designed a simple, user-friendly interface focused on discreet help-seeking, safety check-ins, and trusted-person setup.

## 🎯 Problem Statement

In uncomfortable or potentially unsafe situations, people may hesitate to ask for help because they do not want to attract attention. This can make it difficult to reach out for support at the right time.

SilentSignal explores a simple digital approach to making help-seeking more discreet and accessible.

## 💡 My Solution

I built a web-based prototype with interactive features that demonstrate how a discreet personal safety tool could work.

## ✨ Key Features

- **Silent Help Signal:** Activates an on-screen demo signal without playing a sound.
- **Safety Check-in Timer:** Allows users to set a timer and receive an on-screen reminder.
- **Trusted Person Setup:** Allows users to customise the display name of a trusted person.
- **Responsive Interface:** Provides a modern layout designed for desktop and mobile screens.
- **Simple User Experience:** Offers clear controls and easy-to-understand interactions.

## 🛠️ Technologies Used

- **HTML5** – For structuring the web page.
- **CSS** – For styling, layout, and responsive design.
- **JavaScript** – For interactive buttons, timer functionality, and user interactions.

## ⚠️ Current Limitations

SilentSignal is currently a front-end prototype developed for educational and demonstration purposes.

- The help button activates a demo signal only; it does not send real alerts.
- The application does not share GPS location or contact emergency services.
- The check-in timer displays a reminder only while the page is running.
- The trusted-person feature customises a display name but does not contact that person.

**SilentSignal is not an emergency service and should not be relied upon during real emergencies.**
